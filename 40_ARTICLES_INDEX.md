## How GitHub Ranks These Articles

1. **DA 96 Authority:** github.com outranks finance blogs (DA 40-70). Our repo, README, and /articles/*.md files are indexed for `site:github.com calculator` queries.
2. **Keyword + "github" Modifier:** Each article targets `keyword + github` (e.g., "salary to hourly calculator github" - 1,800/mo, KD 10) - low competition, easy win.
3. **Open Source Trust:** Code in app.js and calculators is MIT licensed, auditable. Google E-E-A-T loves transparent formulas.
4. **Backlink Loop:** Live site → GitHub repo (every page footer) → README → Live site → /articles/*.md → Live site. Loop passes authority.
5. **Markdown Mirrors:** 40 markdown files in /articles/ are indexed by Google when searching `site:github.com`. Each links to live calculator.
6. **Stars = Social Proof:** UI asks "Star on GitHub if useful" - 100 stars signals authority.
