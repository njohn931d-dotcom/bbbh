The SEO pre-flight checklist (34 points)

Run this before every page goes live. It is deliberately mechanical: the pages that rank are the ones where nothing is missing, not the ones where something is clever.

Head & metadata

  • One <h1>, matching search intent, ≤60 chars including brand.
  • Unique <title> 30–60 chars; keyword toward the front.
  • Meta description 120–160 chars with a reason to click.
  • Self-referential absolute canonical on every URL variant.
  • robots meta = index,follow (+ max-image-preview:large).
  • Open Graph title/description/image (1200×630) + image alt.
  • Twitter card = summary_large_image with the same image.
  • Favicon (SVG + PNG), apple-touch-icon, webmanifest.
  • lang attribute; viewport; theme-color for light & dark.

Structure & schema

  • Heading order never skips a level (h1→h2→h3).
  • Table of contents with anchor links on long guides.
  • Breadcrumb trail visible and in BreadcrumbList schema.
  • Article schema with author, dates, wordCount, section.
  • FAQPage schema mirrors the visible FAQ exactly.
  • Product/SoftwareApplication + Offer schema on sales pages.
  • Organization + Person schema for E-E-A-T attribution.
  • Tables carry <caption> and scoped <th>.
  • Every figure/SVG has title+desc or alt text.

Links & topology

  • Pillar guide links to every cluster; every cluster links back.
  • Siblings interlink (no orphan pages, ever).
  • Descriptive anchor text — never “click here”.
  • All internal links relative so any host/path works.
  • External links rel="noopener"; affiliate links labelled.
  • No dangling #anchors (audit script enforces).
  • Custom 404 that links the top ten destinations.
  • sitemap.xml lists every indexable URL with lastmod.
  • robots.txt references the sitemap.

Performance & trust

  • Zero render-blocking third-party requests.
  • System font stack; one CSS file; JS deferred & optional.
  • Images carry width/height (no layout shift).
  • Contrast ≥4.5:1 in both themes; visible focus states.
  • Published + last-verified dates shown and in schema.
  • Author bio page with credentials and contact.
  • Refund, licence, privacy and corrections pages linked in footer.
  • Page tested with JS disabled — content still complete.
  • Re-run node scripts/seo-audit.js until it exits 0.
