## 🛠 Development & Automated Quality Gates

```sh
npm ci                   # Install dependencies
npm run dev              # Local Vite dev server (port 5173)
npm test                 # Run 31 unit, SEO, and cluster tests
npm run build:verify     # Full production build + dist check + strict SEO audit
npm run seo:audit        # Automated audit of dist/ (asserts 0 errors, 0 warnings)
```

The GitHub Actions workflow (`.github/workflows/deploy.yml`) gates every deployment on:
1. `npm test` — 31 tests passing.
2. `npm run build:production` — compiles 142 distinct HTML routes.
3. `npm run verify:dist` — asserts 142 sitemap URLs, 142 HTML files, 0 noindex tags, discovery files.
4. `npm run seo:audit` — exits non-zero on any SEO error or warning.
