Ask a question ↗
Is this a hosted product or a setup service?

It’s a setup service. The pilot is configured in an account you control; this site does not sell or host shared workspaces.

How much does a pilot cost?

It depends on the scope and environment. You’ll receive a fixed quote before any work begins, and your cloud provider bills infrastructure directly to you.

Does this guarantee security or compliance?

No blanket security or compliance guarantee is made. Access requirements and risks must be reviewed for each project. Regulated or sensitive workloads need qualified security and legal review before use.

What happens after the pilot?

You can keep using the setup in your account, ask for a separately scoped rollout, or end the engagement. Ongoing support is optional and agreed in writing.
